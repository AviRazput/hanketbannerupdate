# Category page images

Each category uses the same folder layout so its banner and section images can be changed independently.

```text
category-pages/
  women/
    banner/
    featured-on-hanket/
    shop-by-category/
    trending-now/
    new-arrivals/
    bestsellers/
    instagram/
```

The same layout is available for `women`, `men`, `kids`, `glam`, `home-decor`, `wedding-occasion`, `footwear`, `jewellery`, and `accessories`.
